## Установка
1. Скачайте
2. Распакуйте архив в папку, установите шрифт
3. Профит!

## Редактирование патча
Декомпилировать оригинал через этот [инструмент](https://github.com/Cosetto/Rldev-python) в папку SEEN3

Скопировать содержимое из ToRldev и таблицу с переводом, и запустить `build_translation.bat`
